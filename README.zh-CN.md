# 产业研究图谱 Industry Research Atlas

这是一个可复用的产业研究技能和中英双语 HTML 页面，用来研究：**谁向谁供货、供应什么、产品如何升级，以及风险如何沿产业链传导。**

## 直接打开

双击根目录的 `index.html` 即可使用，不需要 API Key、服务器或安装软件。页面保留最终二维版的产业链、产品说明、示意性产品三维模型、未来情景、国家比较、公司聚焦、关系矩阵和间接联系。

这里是适合公开分享的版本。你已接受的原始最终 HTML 不变；公开包移除了第三方来源截图和未经核实的导入公司标签，保留有来源的研究内容及交互功能。被移除的关系不会变成“已确认供货”。

## 页面怎么看

- **气泡面积**：公司整体市值，可选等比例、压缩或相同大小；不代表光通信业务收入。
- **箭头方向**：供应商 → 客户。合作、竞争与财务关系单独区分。
- **箭头宽度**：当前相同，因为证据没有量化经济依赖程度。
- **产业概览**：按国家和产业环节固定排列，点击公司再展开关系。
- **公司聚焦**：左侧供应商、中间公司、右侧客户，显示产品和来源。
- **关系矩阵**：行是供应商，列是客户；空白表示没有记录，不证明没有关系。
- **间接联系**：共同供应商、共同客户、多步路径是研究线索，不是隐藏合同。
- **冲突模拟**：有条件地假设关系中断，不自动推导收入损失。

## 研究范围

快照日期：2026-09-10。产品和财报信息保留页面各自显示的日期，本次打包没有重新刷新所有财报。

当前共 40 家研究公司，5 条公司确认的直接供货关系，1 条可选的可信第三方供货报道，4 条合作关系和 1 条竞争关系。39 家有带来源的市值，其中 37 家为 9 月 9 日，2 家为 9 月 8 日旧值，仅在详情中显示。1 家市值未知。市值不是实时行情。

这不是完整供应链数据库。缺少记录不等于公司不重要，也不等于它没有供应商或客户。

## 将技能用于其他产业

技能文件夹：`skills/industry-research-atlas/`。

支持本地技能的 AI 助手可以把整个文件夹放入其技能目录；具体安装目录由使用的平台决定。Codex 类本地环境通常使用 `~/.codex/skills/`。下载或上传 GitHub 不会自动在 ChatGPT 账号中安装技能。

兼容的助手可使用：

> 使用 $industry-research-atlas 研究数据中心电力产业，覆盖 GEV、BE、TLN、VRT、CEG。以最新可核实日期为截止，阅读公司财报，验证供应商与客户关系，解释产品升级，区分市值与依赖程度，输出中英双语可交互 HTML。缺失数据明确标注，不能虚构。

如果助手不支持安装技能，可以上传整个包并让它阅读 `SKILL.md` 及其引用文档，然后按这些规则执行。光通信页面是参考，研究其他产业时需要修改 JSON 和 JavaScript 中的产业、产品、公司和情景，不能仅替换页面标题。

## 修改后生成 HTML

在仓库目录中运行：

```bash
python3 scripts/build.py
python3 scripts/validate.py
node tests/check_audit.cjs
node tests/check_2d.cjs
```

生成需要 Python 3.9+；程序化行为检查另外需要 Node.js 18+。生成后的 HTML 使用浏览器即可打开。
