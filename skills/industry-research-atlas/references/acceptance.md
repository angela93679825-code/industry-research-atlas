# Acceptance checks

Verify observable behavior rather than only matching labels.

- Every researched company and industry role is accounted for; unresolved identities remain explicit.
- Every confirmed supply has resolved endpoints, a specific bilingual product, supporting URL, source date and evidence status. Supply arrows and supplier/customer panels agree.
- No partnership, competitor or unverified source-map edge is promoted to confirmed supply.
- Country selection keeps every company in either selected headquarters group visible. Empty companies/cells have correct wording. Optional third-country paths are directed and connect the selected endpoints.
- Bubble area follows the selected financial scale, source units and valuation date. Unknown/stale values are not silently zero or current. Company size is not industry importance.
- Focus cards, matrix cell detail and source links show the same underlying records. Multiple records between the same actors remain inspectable.
- Product/category/route/factory conditions constrain scenario interruptions. Missing location is uncertain. Supply shortage versus customer-demand loss is stated correctly.
- Indirect exposure includes an exact relationship path and remains conditional. Shared-supplier links do not invent a direct A-to-B contract.
- Scenario reset restores the baseline map and clears user route assumptions.
- English/Chinese covers all generated content and preserves selected countries, company, filters, tab, matrix selection and scenario.
- Current product facts and company filing claims are distinct from future scenarios. Undisclosed specifications and quantitative losses are not invented.
- No broken sources, local-only paths, source credentials or copied private exports in a public package.
- Build succeeds from another directory with documented dependencies. Output embeds its data and works without live APIs when advertised as offline.
- For the bundled optical example, run the provided Python validator and Node behavior tests. Adapt test fixtures when changing the sector; do not force a new industry to match optical counts.
- State test limits. Programmatic layout/state checks are not browser interaction or visual inspection.
