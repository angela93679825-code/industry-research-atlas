# Contributing

Keep each factual change reviewable: name the affected company/product, explain the relationship direction, cite the actual supporting source and date, identify evidence status, and provide English/Chinese text. Preserve unresolved gaps rather than filling them from assumption.

Edit `src/` and `data/atlas.json`, then run the build, validator and Node checks documented in the README. Do not edit only index.html. If the reusable reference should also change, update the corresponding `skills/industry-research-atlas/assets/site/` files and document the new snapshot; otherwise it remains the frozen v1.0.0 example.

For another industry, create a separate research branch or project and replace all sector-specific mappings and descriptions. Do not merge fictional test relationships or illustrative financial values into production research.

No secrets, private reports, source screenshots or user-specific exports in public pull requests. Licensing for third-party source data is separate from the original code license.
